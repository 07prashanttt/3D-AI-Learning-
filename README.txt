StudyVerse AI - Built by Prashant vi

Included:
- Responsive futuristic study website
- Synthesized sound effects on clicks (sound toggle)
- AI Tutor integration (Gemini API key optional)
- Browser speech synthesis for spoken tutor answers
- Notes generator, quiz, calculator and subject shortcuts

To use:
1. Extract this ZIP.
2. Open index.html in a browser (or upload the files to GitHub Pages).
3. For live AI answers, create a Gemini API key and enter it in the website.
   The key is stored in localStorage on that browser. Never share it or commit it to GitHub.
4. AI API access may be subject to provider limits, availability and model naming.

The notes tool creates a simple text bullet extraction, not AI summarization without a key.
