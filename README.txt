StudyVerse AI — Pro upgrade by Prashant vi

This version connects these tools to Gemini API:
* AI tutor
* AI notes/summarizer
* AI-generated 5-question MCQ quiz with scoring and explanations
* AI math step-by-step solver
* Subject shortcuts feed the tutor prompt
* Sound feedback for clicks with toggle; browser text-to-speech read-aloud buttons
* Responsive interface

Setup:
1. Extract the zip.
2. Open index.html in browser (or deploy to GitHub Pages).
3. Enter your Gemini API key and Save key.
4. Try each AI tool.

Important security note: this is a browser-only demo/project. The key is saved in browser localStorage and requests are made client-side. Do NOT publish your API key in a public repository or share this deployed version publicly with a personal key. For a public production site, use a server-side backend to protect API credentials. API availability, quotas and model access may vary; the code currently uses gemini-3.5-flash and may need a model name adjustment if Google changes access.
